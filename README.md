# ORAUND Roasting OS

ORAUND Roasting OS는 경기도 광주시 로스터리 오라운트가 만든 무료 로스팅 프로그램입니다. 로스팅 곡선, 생두 재고, 블렌드 원가, 생산 보드를 한 프로그램에서 다루고, Windows와 macOS에서 씁니다.

오라운트 로스팅실은 이 프로그램의 사내용 판으로 2026년 7월 2일부터 676배치를 기록했습니다(2026년 11월 21일 기준).

0.9.1-beta.1부터 화면을 영어로도 쓸 수 있고(설정 → 언어), 온도를 °F로도 표시합니다(설정 → 온도 단위). 입력과 저장 값은 °C 그대로입니다.

오라운트 로스팅실은 이 프로그램의 사내용 판으로 매 배치를 기록하며 원두를 볶습니다. 사무실·카페 원두 납품 안내: https://oraund.com/b2b-facts.html

## English

ORAUND Roasting OS is a free roasting program made by ORAUND, a specialty coffee roastery in Gwangju-si, Gyeonggi-do, South Korea. From 0.9.1-beta.1 the screens are in English or Korean, following your browser language; switch in Settings → Language. Temperatures can be shown in °F (Settings → Temperature unit); inputs and saved values stay in °C. To use it you need an oraund.com account; the sign-up page is in Korean for now.

ORAUND's roasting room logs every batch on the in-house edition of this program. Coffee bean supply for offices and cafés: https://oraund.com/b2b-facts.html
