## C. 선택 기능: 카페24 배송 채널 (준비 중)

로스터리가 이 기능을 켜면, 입력한 택배사와 송장 번호를 그 로스터리의 카페24 주문에 등록해요. 배포본에 연결 서버 주소가 들어 있지 않으면 이 기능은 켜지지 않고, 아무 정보도 오가지 않아요.

**C-1. 주문과 송장: 이 PC ↔ 카페24 (회사 서버를 거치지 않아요)**
- 이 PC와 카페24가 직접 주고받아요(로스터리 쇼핑몰의 카페24 관리자 API). 회사는 이 내용을 받지 않아요.
- 이 PC가 카페24에서 받는 것: 배송을 기다리는 주문 목록(최근 14~90일 — 주문 번호, 주문 날짜, **주문자 이름**, 상품명·옵션·수량, 주문 상태), 쇼핑몰에 등록된 택배사 목록, 송장을 붙일 주문의 상태. 카페24 응답에 다른 주문 항목이 함께 올 수 있지만, 프로그램은 위 항목만 쓰고 나머지는 버려요.
- 이 PC가 카페24로 보내는 것: 주문 번호, 택배사, 송장 번호, 배송 상태 바꾸기 요청.
- 주문자 이름과 상품명은 송장을 맞는 주문에 붙이도록 화면에 보여 주기만 하고 저장하지 않아요. 이 화면은 로그인한 기기면 볼 수 있어요. 이 PC에 남는 것은 B-1의 송장 기록뿐이에요.

**C-2. 연결 승인: 이 PC ↔ 회사의 연결 서버 (Cloudflare)**
- 회사의 연결 서버는 카페24 연결 승인만 중개해요. 주문 목록, 주문자 이름, 상품, 송장 번호는 연결 서버로 가지 않아요.
- 「카페24 연결하기」를 누르면 대표의 브라우저가 연결 서버를 거쳐 카페24 승인 화면으로 가요. 이때 연결 요청 번호, 일회용 확인 값, 쇼핑몰 아이디가 연결 서버로 가요.
- 승인이 끝나면 이 PC는 연결 서버에서 이 설치의 연결 비밀 값을 받아 암호화해서 저장해요. 그 뒤에는 이 값으로 연결 서버에서 짧게 쓰는 카페24 접근 토큰을 받아요(메모리에만 두고 저장하지 않아요). 「연결 끊기」를 누르면 연결 서버에 끊었다고 알리고 이 PC의 값을 지워요.
- 연결 서버는 카페24 앱의 승인 정보(카페24가 주는 갱신 토큰)와 쇼핑몰 아이디, 연결 비밀 값의 확인 정보를 보관해요. 연결 서버와 접속 기록은 국외(Cloudflare, 미국)에 있어요.
- 이 기능은 아직 열리지 않았어요(이 배포본에는 연결 서버 주소가 없어요). 열기 전에 보관 항목과 기간, 국외 이전, 처리 위탁 여부를 이 안내에 적고 프로그램에서 다시 알려 드려요.

## D. 선택 기능: 업데이트 확인

프로그램은 시작할 때(30초 뒤), 대표가 「확인」을 누를 때, 켜 둔 동안 하루에 한 번 회사의 공개 배포 주소에서 새 버전 정보를 받아 와요. 로스팅 중에는 확인하지 않아요. 이 요청에는 일반 인터넷 요청 정보(IP 주소, 프로그램 버전)만 담기고, 업무 데이터는 담기지 않아요. 새 버전 정보는 `https://roasting-os.oraund.workers.dev/update/beta/` 에서 받아 와요. 회사가 Cloudflare Workers로 운영하는 주소예요. 이 주소는 회사의 공개 GitHub 저장소에 올려 둔 배포 파일을 받아서 그대로 전해 주기만 하고, 요청 내용을 저장하지도 기록으로 남기지도 않아요. 다만 하루(세계 표준시 기준)마다 새 버전 확인이 몇 번 왔는지 배포 채널별 합계 숫자 하나만 세요. 이 숫자에는 IP 주소, 설치 번호, 프로그램 버전이 들어가지 않아요. 너무 많은 요청을 막는 데에만 A-5와 같은 방법으로 IP 주소를 메모리 안에서 잠깐 써요. 받은 파일은 프로그램이 서명과 파일 값(SHA-256)을 확인한 뒤에만 써요. PC 관리자는 `.env` 파일에 `POS_UPDATE=0` 을 적어 업데이트 확인을 끌 수 있어요. 꺼도 다른 기능은 그대로 쓸 수 있고, 새 버전은 새 설치 파일로 직접 올릴 수 있어요. 배포본에 업데이트 주소가 들어 있지 않으면 프로그램은 확인하지 않아요.

## E. 선택 기능: 생두 주문

「생두」 화면에서 회사의 생두를 고르고, 주문과 결제는 회사 쇼핑몰 화면에서 해요.

- 생두 목록을 받아 올 때는 개인정보를 보내지 않아요. 일반 인터넷 요청 정보(IP 주소, 프로그램 버전)만 담겨요.
- 주문과 결제는 쇼핑몰 화면에서 이루어지고, 그 처리는 쇼핑몰의 개인정보 처리방침을 따라요. 이 프로그램은 주문 정보, 결제 정보, 배송지를 받지도 저장하지도 않아요.
- 이 PC에는 최근 주문 10줄(생두 코드, 용량, 수량)만 남아요.
- 생두 회원인지는 H의 oraund.com 로그인으로 정해져요. 로그인한 설치는 회원이고, 생두 화면이 따로 회원 연결을 하거나 회원 정보를 보내지 않아요.
- 생두 재고 화면의 생두 카드: 생두마다 최근 로스팅 기록(그 생두가 처음 기록된 뒤 최대 30일)으로 14일분보다 적게 남은 생두를 이 PC 안에서 계산해 「케냐 9일분 — 생두 페이지 열기」처럼 보여 줘요. 계산에 쓰는 기록은 보내지 않아요. 「생두 페이지 열기」를 누를 때만 쇼핑몰의 생두 페이지가 새 창으로 열리고, 주소에는 이 카드에서 왔다는 표시(`utm_source=pos&utm_medium=app&utm_campaign=lowstock`)만 붙어요.

## F. 선택 기능: 도움말 묻기

설치, 로스터기 연결, 사용법을 물어볼 수 있어요. 두 가지 방법이 있어요.

- **이 PC의 Claude Code로 묻기**: 이 PC에 로스터리가 직접 설치하고 로그인한 Claude Code가 답해요. 질문은 그 계정과 그 약관(Anthropic, 미국)으로 처리되고, 회사는 질문을 받지 않아요. 이 PC에 설정된 Claude Code용 API 키(ANTHROPIC_API_KEY)와 프록시 설정은 그 Claude Code에만 넘기고, 이 프로그램은 그 값을 저장하거나 기록하지 않아요.
  - 이때 **Claude Code가 스스로 덧붙이는 정보**도 Anthropic으로 가요: 작업 폴더 경로(이 프로그램이 질문마다 만드는 빈 폴더예요. 경로에 Windows·Mac 사용자 계정 이름이 들어 있을 수 있어요), 운영체제 종류와 버전, 날짜, 그리고 이 PC 사용자가 Claude Code에 저장해 둔 설정과 메모리(예: CLAUDE.md 파일). 이 프로그램은 그 내용을 고르거나 막을 수 없어요.
  - 사용자 계정 이름이 실명이거나 Claude Code 메모리에 개인정보가 있으면, 이 방법을 쓰기 전에 확인해 주세요.
  - 이 프로그램은 Claude Code를 실행할 때 사용 통계·오류 보고·업데이트 확인 같은 부가 전송을 끄는 설정(`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`)을 함께 넘겨요. 그래서 Claude Code는 질문 말고 다른 것을 보내지 않아요.
  - 이 PC 사용자가 Claude Code에 직접 설정해 둔 후크(hooks)가 있으면, 그 후크는 질문 글을 볼 수 있어요.
- **회원 도우미**: 「보내기」를 누를 때만 질문을 회사의 연결 서버(Cloudflare, 국외)를 거쳐 Anthropic(미국)으로 보내요(국외 이전). 이때 연결 번호와 무작위 설치 번호가 같이 가요. 회원 도우미는 아직 열리지 않았어요(이 배포본에는 연결 서버 주소가 없어요). 열기 전에 회사 서버에 남는 것을 이 안내에 적고 다시 알려 드려요.
- 두 방법 모두 이 프로그램이 보내는 것은 적은 질문 글 그대로이고, 「화면 상태 함께 보내기」를 켜면 프로그램 판 번호, 지금 화면 이름, 로스터기 연결 상태 코드가 같이 가요. 이 프로그램은 커브, 배치, 생두, 로스터리 이름, 사람 이름을 덧붙이지 않아요 (위의 Claude Code가 스스로 덧붙이는 정보는 빼고요).
- 질문 글에는 이름, 전화번호, 비밀번호를 적지 마세요. 대표는 「설정 > 도움말 묻기」에서 끌 수 있어요.

## H. oraund.com 아이디로 로그인

이 프로그램은 따로 계정을 만들지 않아요. 대표는 오라운트 쇼핑몰(oraund.com) 회원 아이디로 로그인해요. 한 설치본에 아이디 하나가 연결되고, 직원 계정은 없어요. 로그인은 쇼핑몰의 확인 화면(`https://oraund.com/pos-link.html`)과 회사의 연결 서버(Cloudflare Workers, `https://roasting-os.oraund.workers.dev`)를 거쳐요. 연결 서버는 회원 아이디와 회원 확인 값을 저장하지 않고, 회원 참조 값은 이 PC의 프로그램만 열 수 있게 잠근 상태로 프로그램이 받아 갈 때까지만 둬요.

로그인은 대표가 요청한 ORAUND Roasting OS 로그인을 제공하려는 것이에요(계약). 로그인 확인을 Cloudflare, Inc.의 서버에서 하는 국외 이전은 연결 페이지에서 따로 받는 동의에 따라요(H-7).

### H-1. 로그인할 때 일어나는 일
1. 프로그램에서 로그인을 누르면 브라우저가 열려요. 주소의 `#` 뒤에 10분 동안 한 번만 쓰는 연결 코드, 확인 값, 이번 로그인에만 쓰는 프로그램의 공개 키가 붙어요. `#` 뒤는 웹 서버로 가지 않아요. 프로그램 화면에는 4글자 확인 코드가 보여요.
2. 쇼핑몰 확인 화면은 열리자마자 주소창과 방문 기록에서 이 값들을 지워요. 쇼핑몰 로그인 화면에 다녀오는 동안만 이 브라우저 탭의 임시 저장소(sessionStorage)에 두고, 확인이 끝나거나 오류가 나면 지워요.
3. 쇼핑몰에 로그인돼 있지 않으면 쇼핑몰 로그인 화면으로 가요. 로그인은 쇼핑몰(카페24)에서 하고, 비밀번호는 이 프로그램과 연결 서버로 오지 않아요. 아이디가 없으면 그 화면에서 회원가입할 수 있어요.
4. 확인 화면에 4글자 확인 코드가 보여요. 프로그램 화면의 코드와 같을 때만 「로그인 확인이 Cloudflare(미국) 네트워크를 거쳐 처리되는 것에 동의해요」에 체크하고 「이 PC의 ORAUND Roasting OS에 로그인」을 눌러 주세요. 체크하고 누르기 전에는 아무것도 보내지 않아요.
5. 누르면 쇼핑몰이 회원 아이디를 담아 서명한 회원 확인 값(토큰)을 만들고, 확인 화면이 그 값과 연결 코드, 확인 값, 프로그램의 공개 키를 연결 서버로 보내요. 연결 서버는 서명이 맞는지, 만든 지 10분이 안 됐는지, 오라운트 쇼핑몰이 만든 것인지 확인하고, 회원 아이디를 회원 참조 값으로 바꿔요. 회원 참조 값은 회원 아이디를 회사만 아는 비밀 값으로 변환한(HMAC-SHA256) 22글자 값이라, 이 값만으로는 회원 아이디를 알 수 없어요.
6. 연결 서버는 회원 참조 값을 프로그램의 공개 키로 잠가(암호화해) 프로그램이 받아 갈 때까지 맡아 두고, 토큰과 회원 아이디는 버려요. 받아 가지 않으면 10분 뒤 쓸 수 없게 되고 하루 안에 지워요. 잠근 값은 이 PC의 프로그램만 열 수 있고 연결 서버도 열 수 없어요.
7. 프로그램은 이 PC만 아는 값을 보내 이 PC에서 시작한 로그인인지 확인받고, 잠근 값과 연결 번호를 받아요. 이때 연결 서버는 맡아 둔 값을 바로 지워요.
8. 처음 로그인은 프로그램이 설치된 PC에서만 할 수 있고, 인터넷이 필요해요. 그 뒤로는 처음 로그인한 아이디로만 이 설치에 로그인할 수 있어요.

### H-2. 연결 서버가 보관하는 것

| 항목 | 내용 | 보관 기간과 파기 |
|---|---|---|
| 로그인 대기 기록 | 연결 코드의 해시, 확인 값(이 PC만 아는 값의 해시), 프로그램만 열 수 있게 잠근 결과, 만든 시각과 끝나는 시각 | 프로그램이 받아 가면 바로 지워요. 받아 가지 않으면 10분 뒤 쓸 수 없고, 하루에 한 번 도는 정리에서 지워요(끝난 뒤 하루 안) |
| 연결 기록 | 연결 번호의 해시, 만든 날짜, 마지막으로 확인한 날짜(시각 없이 날짜만, 하루에 한 번만 고쳐요). 누구의 기록인지 알 수 있는 칸은 없어요 | 「연결 끊기」를 하면 바로 지워요. 365일 동안 확인이 없으면 하루 안에 지워요 |
| 하루 확인 수 | 하루(세계 표준시 기준)마다 H-6의 다시 확인에 「연결돼 있어요」라고 답한 횟수의 합계 숫자 하나. 누구의, 어느 설치의 확인인지 알 수 있는 칸은 없어요 | 통계 숫자로 계속 둬요 |

연결 서버는 회원 아이디와 회원 확인 토큰을 저장하지 않아요. 회원 참조 값은 위 표의 잠근 결과로만, 프로그램이 받아 갈 때까지 두어요(받아 가지 않으면 10분 뒤 쓸 수 없게 되고 하루 안에 지워요). 이름, 이메일, 전화번호, 주소, 비밀번호, 연결 코드와 연결 번호 그 자체는 저장하지 않아요. IP 주소는 H-4와 같이 매시간 바뀌는 값과 섞은 해시로만 서버 메모리에 최대 1시간 둬요. 지운 기록은 7일 뒤에는 복구할 수 없어요. 그 7일 동안에도 회사는 지운 기록을 되살리지 않아요.

### H-3. 회원 확인 토큰
토큰에는 회원 아이디가 그대로 들어 있어요(암호화가 아니라 쇼핑몰의 서명이에요). 토큰은 암호화된 인터넷 통신(HTTPS)으로 연결 서버에 가고, 연결 서버는 메모리에서 확인에만 쓰고 저장하지도 기록으로 남기지도 않아요.

### H-4. IP 주소
연결 서버는 IP 주소를 데이터베이스나 기록(로그)에 남기지 않아요. 너무 많은 요청을 막는 데에만, 메모리 안에서 매시간 새로 만드는 무작위 값과 섞어 해시로 바꾼 형태를 서버 메모리에 최대 1시간 두고 버려요. 회원 정보와 연결하지도 않아요. Cloudflare가 서비스 운영과 보안을 위해 스스로 처리하는 접속 정보는 Cloudflare의 방침을 따라요.

### H-5. 태블릿·휴대폰
- 프로그램 화면의 「다른 기기에서 열기」 QR에는 5분 동안 한 번만 쓰는 로그인 코드가 들어 있어요. QR을 찍으면 그 기기가 로그인돼요. 이 코드는 이 PC 안에서만(메모리에 해시로만) 처리하고 밖으로 보내지 않아요.
- 태블릿·휴대폰의 로그인 화면에서 「oraund.com 아이디로 로그인」을 눌러도 돼요. 이때도 H-1과 같은 일이 일어나고, 이 PC에 연결된 아이디가 아니면 로그인되지 않아요.
- 다른 기기의 로그인은 마지막으로 쓴 뒤 14일, 로그인한 뒤 최대 30일 동안 유지돼요. 설정의 「연결된 기기」에서 기기마다 로그아웃할 수 있어요.

### H-6. 이 PC에 남는 것, 다시 확인하기와 연결 끊기
- 이 PC에는 연결 번호, 회원 참조 값, 연결한 날짜와 마지막으로 확인한 날짜만 남아요. 회원 아이디, 이름, 이메일, 비밀번호, 토큰은 저장하지 않아요. 연결 번호와 회원 참조 값은 화면에 보이지 않고 기록에도 남지 않아요. 회원 참조 값은 이 PC 밖으로 보내지 않고, 연결 번호는 인터넷 주소에는 넣지 않고 요청 머리글로만 보내요. 로그인에 쓴 일회용 키는 로그인이 끝나거나 10분이 지나면 버려요.
- 이 PC는 로그인한 채로 열려요. 인터넷이 끊겨도 이 PC에서는 계속 쓸 수 있어요.
- 하루에 한 번 연결 번호만 보내 연결이 살아 있는지 확인해요. 로스팅 중에는 확인하지 않고, 로스팅이 끝난 뒤에 확인해요. 연결 서버가 연결이 끝났다고 답하면 모든 기기에서 로그아웃되고, 이 PC에서 다시 로그인해야 해요.
- 「연결 끊기」를 누르면 연결 번호만 보내 연결 서버의 연결 기록을 바로 지우고, 이 PC의 연결 번호와 회원 참조 값도 지우고, 모든 기기에서 로그아웃해요. 업무 기록은 그대로 남아요. 인터넷이 끊겨 서버에 알리지 못한 연결 기록은 365일 동안 확인이 없으면 지워져요. 연결 기록에는 누구인지 알 수 있는 칸이 없어서, 회사가 회원 아이디로 그 기록을 찾을 수는 없어요.
- 쓰던 아이디로 더 로그인할 수 없으면 이 PC의 로그인 화면에서 「다른 아이디로 다시 연결」을 눌러 안내대로 하면 돼요. 이 PC의 관리 키(`.env` 파일의 OS_KEY)로 확인해요.
- 확인 화면은 쇼핑몰 페이지라서 쇼핑몰의 개인정보 처리방침과, 그 페이지에서 쓰는 분석 도구에 관한 내용이 함께 적용돼요.

## I. 선택 기능: 오라운트 비서 (대표님이 연결한 AI)

「오라운트 비서」는 이 PC의 생두 재고, 로스팅 기록 요약, 생산 계획을 보고 짧게 답하는 화면이에요. 회사가 운영하는 AI가 아니고, 대표가 연결한 AI로만 동작해요. AI를 연결하고 이 안내에 동의하기 전에는 꺼져 있어요(기본 꺼짐). 대표는 「설정 > 오라운트 비서」에서 연결하고, 모델을 고르고, 끄고(동의 철회), 연결을 끊고, 키를 지울 수 있어요.

### I-1. 연결하는 두 가지 방법
- **내 API 키 연결**: 대표가 Anthropic에서 직접 만든 API 키로 연결해요. 질문은 이 PC에서 Anthropic의 API 주소(`https://api.anthropic.com`)로 바로 가고, 대표의 Anthropic 계정과 그 약관·요금으로 처리돼요. 이 프로그램은 Anthropic의 공식 프로그램 라이브러리(@anthropic-ai/sdk)를 쓰고, 이 라이브러리는 요청 머리글에 라이브러리 판, 운영체제 종류, 실행 엔진(Node) 판 같은 기술 정보를 붙여요.
- **이 PC의 Claude Code로 체험**: F와 같은 방법(도구 없이 답만)으로, 이 PC에 설치하고 로그인한 Claude Code가 답해요. F에 적은 「Claude Code가 스스로 덧붙이는 정보」도 같이 가요. 체험용이에요.

### I-2. Anthropic(미국)으로 가는 것
질문할 때, 「브리핑」·「로스팅」을 누를 때, 그리고 하루 한 번(기기마다) 비서 창이 처음 열리며 「오늘 브리핑」을 저절로 받을 때만, 그 순간 프로그램이 모은 아래 칸과 적은 질문이 대표의 계정으로 Anthropic에 가요. 칸은 프로그램이 하나씩 골라 담고, AI는 받은 글로 답만 써요(AI에게 도구는 없어요).

| 묶음 | 보내는 칸 |
|---|---|
| 생두 재고 | 생두 이름, 산지, 가공(그 생두의 가장 최근 로스팅 기록에 적힌 값), 재고 kg, 최근 사용량 kg과 그 기간(그 생두가 처음 기록된 뒤 최대 30일), 남은 일수(또는 「아직 실사 전」·「재고 마이너스」) |
| 로스팅 30일 요약 | 원두(생두·블렌드)별 배치 수, 투입 kg, 평균 감량률, 목표(로스팅 기준 기능이 켜져 목표 감량률·배출 온도·DTR이 있을 때만) |
| 이름 | 레시피 이름, 로스팅 기준 곡선 이름(그 기능이 켜진 경우) |
| 생산 계획 | 오늘(밀린 것 포함)과 오늘부터 7일 동안의 원두 이름과 kg |
| 질문 | 대표가 적은 질문 글 그대로(오늘 브리핑·로스팅 리뷰는 프로그램이 정한 요청 문장) |

- 보내지 않는 것: 고객 이름·주소·전화번호·이메일, 주문과 배송 채널 정보, 직원·매장 이름, 생산 보드의 메모와 손으로 적은 항목, 커브의 온도 점, 테이스팅 노트, 공급처, 가격, 계정, 설정, 키, 기록(로그). 생두·레시피·제품 이름 안에 이 PC에 등록된 사람이나 매장 이름이 들어 있으면 그 부분을 가리고 보내요.
- 질문 글은 적은 그대로 가요. 이름, 전화번호, 비밀번호를 적지 마세요.
- 질문마다 따로 보내요. 앞의 질문과 답은 다시 보내지 않아요.
- 커피 추출·로스팅을 묻는 질문에는 프로그램에 들어 있는 추출·로스팅 기본 지식(일반 지식이에요, 이 PC의 데이터가 아니에요)을 함께 보내요.

### I-3. 회사가 받는 것
회사는 질문, 답, 위의 칸 가운데 어떤 것도 받지 않아요. 이 기능은 회사의 서버를 거치지 않아요. 답에 생두가 모자라다는 말이 있으면 프로그램이 E의 생두 카드를 같이 보여 줘요. 카드의 생두와 링크는 프로그램이 정하고(AI가 쓴 주소나 상품 이름, 가격은 화면에서 지워요), 「생두 페이지 열기」를 누를 때만 쇼핑몰 페이지가 새 창으로 열려요.

### I-4. API 키 보관과 지우기
- 키는 이 PC의 운영체제 보관함에만 저장해요. Windows는 DPAPI로 지금의 Windows 사용자 계정만 풀 수 있게 잠가 데이터 폴더의 `assistant\key.dpapi` 파일에, Mac은 로그인 키체인(`roasting-os-assistant` 항목)에 저장해요. 키를 넘길 때도 명령줄에 적지 않고 표준 입력으로만 넘겨요. `.env` 파일, 프로그램의 데이터베이스, 백업, 기록(로그)에는 저장하지 않아요.
- 저장하기 전에 Anthropic에 키가 맞는지 한 번 확인해요(모델 정보 조회, 요금 없음). 맞지 않는 키는 저장하지 않아요.
- 저장한 뒤에는 화면에 마지막 4글자만 보여요(「연결됨 · …abcd」). 키를 화면이나 다른 기기로 다시 보내지 않아요.
- 「키 지우기」나 「연결 끊기」를 누르면 보관함에서 키를 지워요. 프로그램을 지울 때 데이터까지 지우면 Windows의 키 파일도 지워져요. Mac에서 프로그램만 지웠다면 키체인 접근 앱에서 `roasting-os-assistant` 항목을 지우면 돼요.
- 키로 쓴 요금은 대표의 Anthropic 계정으로 나가요. 키가 새어 나갔다고 생각되면 Anthropic 콘솔에서 그 키를 바로 폐기해 주세요.

### I-5. 이 PC의 Claude Code로 연결할 때
F의 설명이 그대로 적용돼요. 이 PC의 Claude Code에 저장된 설정과 메모리가 같이 가고, 대표가 Claude Code에 직접 만든 후크(hooks)는 질문과 위의 칸이 담긴 글을 볼 수 있어요. 이 프로그램은 Claude Code의 부가 전송을 끄는 설정(`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`)을 함께 넘겨요.

### I-6. 끄기(동의 철회)와 연결 끊기
- 「동의 철회(끄기)」를 누르면 바로 꺼지고 아무것도 보내지 않아요. 연결은 남아 있어서 다시 동의하면 켜져요.
- 「연결 끊기」는 연결을 끊고 저장한 키도 지워요.
- 이미 Anthropic으로 간 내용의 보관과 삭제는 Anthropic의 정책과 대표의 Anthropic 계정 설정을 따라요.
